# C# ADSO - Sesión 1

Ejercicios de aprendizaje de C# para el programa de Análisis y Desarrollo de Software (ADSO).

## Comparación de instrucciones

| ¿Qué quiero hacer? | Python | JavaScript | C# |
|---|---|---|---|
| Mostrar un mensaje | `print("Hola")` | `console.log("Hola");` | `Console.WriteLine("Hola");` |
| Mostrar sin salto de línea | `print("Hola", end="")` | `process.stdout.write("Hola")` | `Console.Write("Hola");` |
| Leer un dato | `nombre = input()` | `prompt("Nombre:")` | `Console.ReadLine()` |
| Unir texto y variables | `f"Hola {nombre}"` | `` `Hola ${nombre}` `` | `$"Hola {nombre}"` |
| Crear una variable entera | `edad = 18` | `let edad = 18;` | `int edad = 18;` |
| Escribir un comentario | `# comentario` | `// comentario` | `// comentario` |

## Proyectos

- `Practica1`: primer programa de consola.
- `Reto`: calculadora de propinas.
- `Tarea`: ejercicios de segundos a reloj, conversión de temperatura y promedio de notas.
